# 0073 computer use の操作中の表示と会話の中の表示

- 状態: 提案

## 状況

エージェントが PC を操作している間、人には「今エージェントが動かしている」「どの会話が」「どう止めるか」が見えていなければならない。会話の中では、今の MCP の行のままだと座標の JSON しか出ず、撮った画面も残らない。

形は 2026-10-01 にモックでユーザーが承認した。

## 決定

### 操作中のディスプレイ（オーバーレイ）

- 操作中のディスプレイだけに、透明・クリックを通す・最前面の窓を重ねる。オーバーレイの窓は撮影から外す（`setContentProtection`）。
- 縁: 外側 1.5 DIP の `#8f9cf0` + 内側 1.5 DIP の `#5665cd`（.95）+ 内側へ薄くなるにじみ（`#8f9cf0` .85 と `#5665cd` .7 の 2 層）。深さは静止時 30 DIP、呼吸で 24 ↔ 36 DIP、周期 4.0 秒（sine の in-out）。明るさは変えない。
- ピル: 上端中央、上から 12 DIP、高さ 32 DIP、左右 14 DIP、13 DIP の Segoe UI Variable、白字、地 `#3a499e`、縁取り 1 DIP の `#8f9cf0`（.7）、影 0 3 14 rgba(0,0,0,.3)。文言は「{エージェント名} が操作中「{会話のタイトル（16 字で切る）}」· Esc で止める」。
- カーソル: 直径 60 DIP の霧（中心 `#8f9cf0` .85 → 34% で `#5665cd` .55 → 70% で 0、ぼかし 3 DIP）に包まれた 17×22 DIP の矢印。2 次ベジェの経路で 320〜900ms で動き、押すと沈む。システムのカーソルは置き換えない。
- 入り: グロー 480ms、ピルは 120ms 遅れて 320ms で降りる。出: 最後の操作から **6 秒**かターンの終わりで、グロー 600ms・ピルとカーソル 240ms。Esc ではピルを「止めました」にして 1.2 秒残す。
- 動きを減らす設定では呼吸と経路を止め、入り・出は不透明度だけ 150ms。
- 承認を待っている間は何も出さない。
- Esc はオーバーレイが出ている間だけ握る。

### 会話の中

- 連続した computer use の呼び出しを「コンピューターを操作中 · N」の塊にする。各行の主役はエージェントが書いた `title`、補足はアプリ名。
- 実行中は見出しと経過、右に「止める」。行は今のまとまりと同じ 3 行。完了後は最大 3 行（失敗・最後に撮った画面・最後の行を優先）と「ほか N 件」。
- 失敗は見出しの右に「✕ 失敗 N」。Esc・止める・ロック画面・禁止・拒否・待ちの打ち切りは、理由を最後の行に書き、失敗に数えない。確認なしで許可したときは「許可 · 確認なしのため自動」を残す。
- 撮った画面は行のサムネイルにし、押すと拡大する。拡大では ← → で同じ塊の画面を順に見られる。消えた画面は「画面は消去済み」。
- 待っている会話の行には「別の会話（{タイトル}）が操作中です。終わったら続けます」と「その会話へ移る」。脇の一覧は走っている弧のまま（◆ は使わない）。

### 承認のカード

- 入力欄のすぐ上、まとまりの最新の行の場所に出す（モーダルにしない）。見出しは「{エージェント名} に「{アプリ名}」の操作を許可しますか？」。
- ボタンは今の承認カードと同じ並び（文字だけ「常に許可」・薄い面「拒否」・塗り「この会話で許可」）。説明文は初めての 1 回だけ。高リスクは ⚠ と強い字の一言を足す（警告色は使わない）。
- Pleiad が背面にあるときは OS の通知で承認待ちを知らせる。

### 設定 › コンピューターの操作

- 全体のスイッチ（既定オン）、すべてのアプリを許可（既定オフ。オンの間は一覧を薄くして「すべて許可中」）、常に許可したアプリの一覧（「消す」は確認なし）、操作できないアプリ（見るだけ）。「Antigravity では承認を聞きません」の 1 行。
- スイッチを切ると下を隠すが、許可は残す。デスクトップ版でないときはスイッチを止めて理由を書く。

## 理由

縁とピルで「誰が・どの会話が・どう止めるか」を画面の上で示し、6 秒で消すので人が戻ってきたときに邪魔をしない。色は Pleiad の操作色に寄せ、暗い壁紙でも縁が立つよう明るい側の線を足した。会話の中では、座標ではなくエージェントの説明と撮った画面で、何をしたかを後から追える。止めたものを失敗に数えないのは、人が意図して止めたものを失敗として目立たせないため。

## 影響

- オーバーレイの CSS は `desktop/` に置き、web の design-lint の対象にしない。数値は `docs/design-system.md` に書く。
- 文言は辞書（`web/locales/*/ui.json`・`desktop/i18n.cjs`）に置く。
