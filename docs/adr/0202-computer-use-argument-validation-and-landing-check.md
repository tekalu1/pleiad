# ADR 0202: computer use の引数は検査して断り、入力が狙いに届いたかを確かめる

- 状態: 提案
- 日付: 2026-10-10
- 関連: [computer-use.md](../computer-use.md)「共通の引数と結果」「失敗と止めた理由」、[ADR 0071](0071-computer-use-approval-and-safety.md)

## 状況

- 子のエージェントが `left_click` に `x` / `y`（文字列）を渡した。正しい形は `coordinate: [x, y]`。サーバーは知らない引数を黙って捨て、`coordinate` を省いた形（今のカーソルの位置を押す）で実行して `ok` を返した。押された先は、そのときカーソルのあった窓だった。
- カーソルが Pleiad の窓の上にあったときは、同じ呼び出しが `forbidden`（`app: Pleiad`）になったが、文に判定した位置が無く、モデルには原因が分からなかった。
- `mouse_move`・`wait` は `invalid` とだけ返し、どの引数が悪いかを書かなかった。
- `ok` は SendInput が成功したことだけを意味した。カーソルが狙いに届いたか、押した先の窓が判定した窓かは見ていなかった。
- ツールが deferred（名前だけが見え、スキーマは読み込むまで見えない）のとき、モデルは引数名を推測して呼ぶ。

## 決定

1. **引数は呼ぶ前に検査して断る。** 知らない引数・足りない必須・型の違いは、ロックを取る前に `invalid` で返し、何も送らない。`tools/list` のスキーマは全ツールで `additionalProperties: false`。文には悪い引数名・正しい引数名と形・渡された値を書く。`x` / `y` は `coordinate: [x, y]`、`x1..y2` は `region: [x0, y0, x1, y1]` と書く。`computer_batch` は動作の引数も先に全部検査する。
2. **`x` / `y` を `coordinate` の別名として受け付けない。** 間違った形を通すと、スキーマを読まない呼び出しがいつまでも直らず、座標の取り違え（数の文字列・画像と画面の座標の混同）も黙って通る。
3. **押す・動かすの結果には位置を書く。** 座標を省いたときは「今のカーソルの位置 (x, y) に対して行った」と書く。`forbidden` の文には、判定に使った位置（座標を省いたときはカーソルの位置・キーは今の前面のアプリ）を書く。
4. **届かなかった入力は `ok` にしない。** main は `input` の返り値に、送った後のカーソルの位置を載せる。座標つきの操作で狙い（`drag` は終点）から 4 画素より離れていれば `missed`（failed）にする。
5. **押す直前に点の下の窓を確かめ直す。** core は押す動作（`click` / `down` / `drag`）に、判定して通したアプリを `expect` で渡す。main は送る直前に点の下の窓を引き直し、`expect` と違えば何も送らずに `target_changed` を返す。core はこれを `point_changed` にする。

## 理由

- 黙って捨てる実装は、書き間違いを「カーソルの位置への操作」という別の有効な操作に変える。入力の取り消しは効かないので、実行前に断るほうが安全。
- 別名を受けない代わりに、誤りの文を、スキーマを見ていないモデルが 1 回で直せる形にする。
- `ok` の意味を「狙いの位置に入力した」に近づける。4 画素は、物理座標への丸めと SendInput の絶対座標の丸めで出る差より十分大きく、別の窓や別の位置へ飛んだ差よりは小さい値として決めた。
- 判定（core の `appAt`）と送信の間に窓が重なる・動く隙があるため、送る直前に main が同じ見方で引き直す。`expect`（判定して通したアプリの pid とパス）を、押す動作の `input` に渡す。

## 影響

- 知らない引数を付けていた呼び出しは `invalid` になる（今までは黙って通った）。
- カーソルが狙いに届かなかった操作は、入力が実際には届いていても `missed` を返す（確かめさせる側に倒す）。`missed` は入力を送った後に出るので、取り消さない。
- 押す直前の確かめは、点の下の窓を 1 回引き直す分だけ遅くなる。
- ツールの説明に、座標を省いた意味と `coordinate` の形を書いた（ja / en）。
- 試験: `tests/unit/computer-bridge.mjs`（引数の誤り・位置・`missed`・`point_changed`・`forbidden` の位置）、`tests/unit/computer-native.mjs`（押す直前の `expect`）。本物の画面で入力する試験はしていない。
