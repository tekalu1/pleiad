# 0152 無停止の更新の切り替えを待つ表示（脇の下の知らせの中の一覧）と、止まるものは待たず聞く

- 状態: 承認（2026-10-06）
- 関連: [ADR 0151](0151-zero-downtime-update.md)（9 の「切り替えの先送り」）、[ADR 0036](0036-interrupt-and-update-while-running.md)、docs/zero-downtime-update/design.md §6.1、docs/design-system.md「切り替えを待つ表示」

## 状況

無停止の更新（ADR 0151）の段階 1 では、更新の後、新しい main は古い版のサーバーに付け直し、作業が 0 件になるまで新しい版のサーバーへの切り替えを先送りする。その間（数分〜数時間）の表示と、`!` のシェル・Codex の裏の端末のように「作業の件数に数えられず、サーバーが終わると止まる」ものの扱いを決める必要があった。実装は仮に、それらも「終わるまで待つ」としていた。

## 決定

利用者が AsIs / ToBe のモックを見て決めた（2026-10-06）:

1. **置き場所は、脇の下の更新の知らせの中で一覧を開く。** 畳んだ脇・狭い窓は ⚙ の点と、設定 › アプリ情報・更新の同じ一覧で補う。待つ間の中断ボタンは塗らない
2. **切り替えで止まるものは、待たず、黙って止めもしない。** 作業が終わったとき、止まるものが残っていれば自動では切り替えず、一覧を見せて「あとで／止めて切り替え」を聞く（ADR 0151 の 9 の「止まるものは無い」ことを自動で切り替える理由にする、という前提を保つ）
3. 一覧の見出しに待ち始めた時刻（「14:32 から」）を出す
4. 切り替えに失敗して前の版で動いている知らせに「もう一度試す」を置く（切り替えをやり直す。作業が残っていればまた待つ）
5. 形式番号が変わる版を押す前には知らせない（窓が入れ替わった後、新しい main が気付いて「あとで／中断して切り替え」を聞く）
6. 押す前の確認の段は、無停止の更新のときだけ「作業は止まらない」の 1 行にし、内蔵ブラウザーのタブ・コンピューターの操作があるときだけ開き直しの注意を足す
7. リモート（スマホ）の画面には待ちの知らせを出さない。切り替えが済むまで「更新しました」を出さない

実装の取り決め:

- 待っている間の窓は古い版のサーバーが配る古い版の画面なので、表示のコード（`web/switch-notice.mjs`）は「その版の画面」に入り、新しい main（`desktop/switch-screen.cjs`）が preload の `plyDesktop.switch`（版 1）で状態を渡す。口は版つき（`switch`・`switch2`…）で、新しい main は 1 版ぶん前の口と形を残す。画面は読み込むとき hello で使う版を知らせ、**hello が来た画面にだけ表示を任せる**。来ない画面（この機能を持たない版）には、main が最小限のダイアログ（止まるものが残ったとき・合わない版・前の版に戻したとき）だけを出し、待っている間は何も出さない

## 理由

- 数時間続きうる待ちを会話の上端の帯で占めない。押す前の確認の中身（一覧・注意書き）が同じ場所に来る
- 止まるものを待つ（仮の実装）と、終わらないもの（`npm run dev`）があるときに何も言わずに切り替わらず、何が原因かが「実行中」の行に紛れる。待たずに止めると何も聞かずに dev サーバーを止める。聞くのは、止めずに放置もしない道
- 画面が表示を持たない版のために、古い版の画面を前提にした最小限の main 側の知らせを残す（無言で聞かないと、止まるものが残ったときに誰も気付けない）

## 影響

- `desktop/switch.cjs` の待ちは work の `count` だけ（止まるものは `waiting.stoppers`）。`asking`・`held`（reason: `stoppers`）・`retry()`・`answer()`・待ち始めの時刻（`since`）・中断の進み・切り替えで止めたもの（`stopped`）を持つ
- `web/index.html`・`web/updates.css`・`web/switch-notice.mjs`・`web/updates.mjs`・辞書（`switch.*`・`updates.handover*`）
- 口の版を上げるときは `switch-screen.cjs` の `BRIDGE_VERSIONS`・`payloadFor`・preload の口を足し、前の版を 1 版残す。テストは `tests/unit/desktop-switch.mjs`（preload の名前の一覧）・`desktop-switch-screen.mjs`・`web-switch-notice.mjs`・`tests/browser/switch-notice.cjs`
