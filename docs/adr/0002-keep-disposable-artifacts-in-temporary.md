# 0002 使い捨てのものを追跡しない（temporary/）

- 状態: 承認（2026-09-26）

## 状況

画面の案を HTML のモックで作ってユーザーに見せ、承認されたものを `docs/mockups/` にコミットしていた（2026-09-26 に 19 件）。文書とコードのコメントは「承認済みのモック [x.html](mockups/x.html)」とモックを指し、承認の記録をモックが兼ねていた。調査メモ・スクリーンショットも docs に入ることがあった。
モックは実装が進むと今の画面とずれるが、直す人はいない。リポジトリが重くなり、どれが今の正かが分かりにくくなる。

## 決定

- モック・調査や提案のメモ・スクリーンショット・一回きりのスクリプトは、メインの作業ディレクトリの `temporary/` に置き、コミットしない（`.gitignore` 済み）。worktree で作業していても、絶対パスでメイン側に書く（worktree の中の `temporary/` は worktree と一緒に消える）。
- 置き場は `temporary/mockups/<題>.html`・`temporary/reports/<題>.md`・`temporary/screenshots/<題>-<場面>.png`・`temporary/scripts/`。題は英小文字とハイフン。改訂は上書きし、並べて比べる版だけ `-v2` などを付ける。
- コミットするのはコード・テスト・今の動きを書いた文書・ADR だけ。
- 承認された形は、モックへのリンクではなく、決まった形と日付を living doc の本文に書く（「承認済み（2026-09-25）」）。理由を残す価値があれば ADR にする（0001）。コード・テストのコメントもモックではなく文書の節を指す。
- 2026-09-26 に `docs/mockups/` を削除し、参照を上の形に置き換えた。調査の記録だった docs（HTML・画像の共有の調査、タイムラインの画像の調査、自己署名版の検証）も削除し、残す結論は ADR と living doc に移した。

## 理由

- 追跡するものを「今の正」だけにすると、読む人が迷わない。
- モックは承認の瞬間の材料で、承認の後は文書の本文が正になる。材料は手元に残れば足りる。
- 採らなかった案: モックを残して「古い」と印を付ける（誰も直さないので印も古びる）、別リポジトリに置く（手間の割に読まれない）。

## 影響

- 手元のモックは `temporary/mockups/` にある（削除した 19 件も写してある）。他の PC・他の人からは見えない。
- AGENTS.md「使い捨てのもの（temporary/）」がこの規則の置き場。
