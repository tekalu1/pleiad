# 0096 bot は定義とスレッドごとの会話でできていて、明示の @ だけで起こし、呼び合いに上限を置かない

- 状態: 提案

## 状況

bot（0093）をどう動かすかを決める。常駐のプロセスを持つ案、bot ごとに 1 本の会話を持つ案、スレッドごとに会話を作る案がある。バックエンドには差がある（Claude と Codex は走っているターンへ途中送信できる。Antigravity は途中送信も圧縮の検出も無く、指示はプロセスの起動時にしか渡らない）。画面の購読は 1 接続 1 会話（[ADR 0024](0024-watch-open-session-stream.md)）なので、複数の bot の生の流れをスレッドへ流せない。

2026-10-03 に、ユーザーが次を決めた: bot 同士の呼び出しに上限を置かない（止めたいときは人がスレッドの [止める]）、Antigravity の承認モードは「全部自動」だけ、全部自動のモードではフォルダーを限れないと表示する、アカウントの選択は bot の画面から外す。

## 決定

- **bot の実体は定義（`bots.json`）。** 名前（チャンネルを通して一意）・アイコン（絵文字 1 つ）・人格（自由文。1.5k トークンまで）・バックエンド / モデル / エフォート・承認モード・触れてよいフォルダー・他の会話に送るか（既定 ON。0101）・DM。**動くのはスレッドごと・bot ごとの会話**（普通のセッション。sidecar の `bot` に botId・種類 `thread|dm|routine|learner`）と、bot ごとに 1 本の DM の会話（スレッドは作らない）。常駐のプロセスは持たない。
- **bot の会話は Chats の一覧に出さない。** あなたを待っている間（承認・質問）だけ出す。完了のスマホ通知は送らず、承認・質問・失敗は送る。放置圧縮は対象にする。検索は既定で除く（委譲の子と同じ）。
- **起こすのは本文中の明示の `@名前` だけ。** 自分自身への @ は数えない。コードの区間と引用の中は数えない。DM では人の投稿はすべてその bot 宛て。スレッドで @ の無い人の投稿は、そのスレッドで今作業中の bot が 1 体だけならその会話へ書き足し（途中送信）、0 体なら誰も起こさず、2 体以上なら起こさず入力欄の上に淡い提案を出す。人が次に書くまで新しく起こさない状態（[止める] の後）を持つ。
- **bot 同士の呼び出しに上限を置かない。** 返事と `channels.post` の @ で相手を同じ規則で起こす。起こした回数と使ったトークンを数えて静かに見せるだけ。止めるのは人が [止める]（そのスレッドの全ての bot の走っているターンを止め、保留中の出来事を取り消し、誰が止めたかをスレッドに残す）。
- **届け方は委譲の完了通知と同じ道。** 走っているターンがあり途中送信できるなら書き足し、無ければ新しいターン、Antigravity と忙しいときはターンの終わりにまとめて 1 通。結果が分からないものは自動では送り直さない。bot へ届ける前の出来事は `inbox.json` に保存してから送り、再起動で送りかけは `unknown`、未送は順に配り直す。
- **スレッドには生の流れを流さない。** 投稿の進捗（同じ投稿を置き換える）・最終の返答・提示だけをサーバーで投稿に畳んで配り、細部は「会話を開く」で Chats 側へ。
- **権限。** 承認モードは人間だけが変える（`bots.setMode` は human-only。[ADR 0082](0082-control-surface-principals-and-risk.md)）。人間だけの操作は承認モード・秘密の値・アカウント・接続先の既定・リモートのペアリングの 5 つで、bot の操作もこの範囲に従う。Antigravity は「全部自動」だけ（確認を挟む手段を持たないため）。フォルダーの選択を「すべてのフォルダー」で無効にするのは、実際に書き込みの範囲を限れないモード（Claude の bypass・Antigravity・Codex の sandbox を外すモード）だけ。Codex の full が sandbox で作業場所に限っているなら、選択は活性のまま。アカウントは bot では選ばせず、既定のアカウントで走る。
- **操作の危険度。** `channels.post`・`channels.react` は write で `modeGate: false`（読み取り・計画の bot も返事はできる）、`bots.create` は write（AI が作るときは guarded）で既定の弱いモード、`bots.setMode`（承認モードだけ）は human-only、フォルダー・他の会話に送るか・送れる会話は `bots.update` の欄で write（範囲を広げる向き = フォルダーを足す・送る先を足す・送るを ON にするは guarded、狭める向きは write）、`bots.delete` は guarded。`channels.markRead` も AI と CLI に出す（write）。bot の道具（投稿・リアクション・記憶）は直のツールを足さず、`list_ops` / `call_op` から呼ぶ。人格の固定の文によく使う操作の id を短く書く。

## 理由

- スレッドで会話を区切ると各会話が短く、圧縮のたびの全キャッシュ切れも文脈の濁りも避けられる。人格は会話の先頭に置いて共通にできる。
- 暗黙の呼び出し（返事の中の名前で起きる）は、2 体が返し合う暴走の元になる。明示の @ だけにすれば、起こした理由が投稿から分かる。
- 上限を置くと、上限の札・確認の札が仕事を止める。止める権限を人に残し、数と費用を見せるほうを選んだ。
- 採らなかった案: 常駐プロセス（Antigravity で 1 体 150〜220MB）、bot ごとに 1 本の会話（上記）、呼び出しの深さ・時間当たりの数の上限（承認済みの決定で外した）、bot が承認を代わりに押す（0101）。

## 影響

- **権限の踏み台:** 読み取りの bot が、全部自動の bot を @ で起こせる。決定どおり確認は置かない。bot の承認モードは人だけが決め、bot の会話は会話に束縛された agent として表に載る。
- **費用の暴走:** 上限が無いので、同時のターン数とトークンは利用者の目と [止める] に任せる。将来の歯止め（1 時間の bot ターン数など）は新しい ADR で置く。
- Codex は指示が変わるとスレッドを読み直すので、人格の変更は高くつく（docs に書く）。Antigravity は人格の変更で起こし直す。
- 古い版へ戻すと bot の会話が Chats に並ぶ。
