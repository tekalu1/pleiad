# 0076 入力欄の上の 1 本の帯とバックグラウンドの入口のチップ

- 状態: 承認（2026-10-02）

## 状況

入力欄の上は、文脈の帯（メーター・自動圧縮の予約）と、右寄せの独立した行「◠ バックグラウンド N」の 2 段だった。狭い画面（360 幅）では文脈の帯が 600px 以下で折り返し、メーターと予約の間に行間 12px が入る。会話末尾の稼働表示と合わせると最大 4 段になり、会話の下端から入力の箱までが 92px、会話の高さが 412px（640px の電話）まで減った。

- 押せる大きさも足りなかった（バックグラウンド 26.5px・メーター 25.6px・キャンセル 17.6px）。
- 同じ「この会話の状態」の小さな字が、右寄せの行（バックグラウンド）と左寄せの帯（文脈）の 2 か所に分かれ、右端もそろっていなかった。
- 「バックグラウンド N」は本数しか語らず、横に長い（117px）。何が動いているか・誰が承認を待っているかが入口では分からなかった。

形は 2026-10-01〜10-02 にモック（AsIs / ToBe、360・1280 幅、ライト・ダーク）でユーザーが承認した。

## 決定

形・大きさ・出る条件は [design-system.md](../design-system.md) の「会話の圧縮」（入力欄の上の帯）と「バックグラウンド」。

- **1 本の帯**: `#workEntry` を `#contextStrip` の右端へ移し、折り返さない 1 行にする。左に文脈、右端にバックグラウンドのチップ。広い画面にも同じ帯を当てる。チップは見た目 28px・押せる範囲 36px。文脈は常に出す（使用率が低いときに隠す案は、帯の出入りで会話の高さが変わりメーターの場所を覚えにくいので採らない）。
- **480px 以下の縮め方**: メーターは「文脈 ▬ 30% · ◷ 17:57」。数値（301k / 1000k）と予約の文はメニューの頭と読み上げ名へ、予約のキャンセルはメーターのメニューの先頭へ移す（1 タップ → 2 タップ）。圧縮中はメーターの位置に弧と「圧縮しています…」、失敗は「⚠ 圧縮できませんでした」と帯に直接の「再試行」（失敗は急ぐ操作なのでメニューに隠さない）。481px 以上は左を従来の字のまま全部出す。
- **`role=status` は文だけ**: 予約・圧縮中・失敗の文だけに付け、ボタンの名前を状態として読ませない。
- **狭い画面の `#log` の下余白**: 24px → 12px。最新へを出す判定（`END_GAP`）も合わせる。稼働表示は会話の筋の末尾の節のまま動かさない。
- **バックグラウンドのチップ**: 動いているものを種類ごとにまとめたアイコンで見せる（エージェントは接続先のロゴ、コマンドは `>_`）。2 本以上は右下に数、4 種類以上は 3 つ＋「+N」、並びは固定（Claude・Codex・Antigravity・互換・ターミナル）、動いている弧は左に 1 つ、終わったものだけなら「✓ N」。字を消すので、読み上げ名と title に「バックグラウンド: Claude 2・Codex 1・ターミナル 1。一覧を開く」を必ず持つ。
- **承認待ちの印は `--ink-mark` の ◆**: 承認待ちを含む種類をロゴの右上の ◆ で示し、その種類を先頭へ寄せる。「+N」には隠さない（承認待ちの種類は 3 を超えても全部出す）。
- **ロゴは重ねず 6px 空けて並べる**。
- **承認待ちは Pleiad タスクの子だけ**: ネイティブのサブエージェントには待ちの状態が無いので、◆ は `taskWaiting` の子にだけ付く。

採らなかった案:

| 案 | 理由 |
|---|---|
| メーターを見出しへ移す | 見出しの「35%」は利用枠のチップで意味が違い、混ざる。 |
| 入力の箱の中のチップ行へ入れる | 360 幅では添付・作業ディレクトリ・モデル・モードと送信で埋まっている。 |
| 稼働表示を帯へ移す | 会話の筋の末尾の節と決めている（design-system §6）。 |
| 文脈を 50% 未満で隠す | 上記。帯の出入りで会話の高さが 36px 変わる。 |
| 種類ごとにロゴを少し重ねる | 下の理由。 |

実装中に、承認時のモックから次を変えた（理由つき）。

- 承認待ちの点は `--amber` 系ではなく `--ink-mark`。
- メーターが開いている間は、棒の地を `--surface-3` ではなく `--surface-2` にする（メーターの面と同じ色になり、棒が見えなくなるため）。
- メーターのメニューは幅を内容に合わせる（最大 300px）。「17:57 の自動圧縮をキャンセル」が折り返さないようにする。
- 481px 以上では、失敗のときもメーターを残す（左は従来の字のまま、という決定を優先）。480px 以下だけメーターを失敗のチップに替える。

## 理由

- **`--ink-mark` の ◆**: トークンに amber は無く（`web/tokens.css`）、`--ink-mark` は「あなたを待っている」専用の差し色。脇の行の待ち（`.side-mark[data-kind=wait]` の ◆）・会話の地図の ◆・承認カードと同じ意味になる。新しい色を足すと、同じ意味に 2 色ができる。
- **ロゴを重ねない**: 重ねると右下の数がとなりのロゴに隠れ、Claude の放射形が欠けて読めない。並べても 3 種類＋数で約 110px で、今の入口（117px）より長くならない。
- **帯を 1 本にする**: 同じ「この会話の状態」を 2 段に分けず、右端をそろえる。折り返しの行間 12px と余白を落とすと、92px が 40px になり、会話が約 50px 広がる。
- **押せる大きさ**: タッチの決まり（見た目 28〜36px・押せる範囲 36px 以上）に、帯のチップをそろえる。
- **種類ごとのまとめ**: 本数ではなく「何が動いているか・誰が待っているか」を入口で見せる。数は種類ごとなので、本数が変わっても位置が入れ替わらない。

## 影響

- `web/index.html` の `#workEntry` が `#contextStrip` の中へ入る。帯を出すかは文脈の側とバックグラウンドの入口の両方で決める（どちらも無ければ帯ごと隠す）。
- 狭い画面（480px 以下）かどうかで、メーターの中身・メニュー・状態の文を JS が描き分ける（`matchMedia('(max-width:480px)')` の変化で描き直す）。
- 新しい `web/background-chip.mjs`（チップの描画。差分だけを描き替える）と、`web/background-model.mjs` の `backgroundSummary`（種類のまとめ。DOM を使わない）。`web/icons.mjs` に `TERMINAL_PATHS`。
- 旧い辞書キー `activity.background`・`activity.backgroundEnded` は廃止し、`activity.bg*`・`compaction.*Short` などを足す。
- 狭い画面の `#log` の下余白が 24px から 12px になる。最新へを出す判定の余白も合わせる（`web/conversation-nav-view.mjs`）。
- バックグラウンドの入口を探すテスト・操作は、ボタンの id（`#workEntryButton`）を使えば変わらない。字（「バックグラウンド N」）では探せなくなった。
