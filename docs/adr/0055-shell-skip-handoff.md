# 0055 入力欄の `!` の行ごとに「渡さない」を選べるようにする

- 状態: 承認（2026-09-28）

## 状況

[ADR 0054](0054-shell-from-composer.md) で、入力欄の `!` で走らせたシェルの結果は会話にすぐ行として積み、エージェントには**次の人の発言と一緒に必ず**渡すことにした。

- 見るためだけに走らせたコマンドや、秘密を含む出力（設定・トークン・顧客のデータ）も、次の発言で LLM の提供元に渡り、transcript にも残る。走らせる前に渡すかを決めることはできない（走らせてみるまで出力が分からない）。
- 承認済みのモック（システム側のメッセージの場面 4b ③）は、走っている行の見出し「あなた · 次の発言で Claude に渡す」の横に「渡さない」を置いていた。0054 の実装では作っていなかった。
- 渡し方はバックエンドで違う。Claude・fake（`capabilities.shell === 'host'`）は Pleiad が結果を sessions.json の `shellPending` に貯め、次のターンの始めに渡す。Codex（`'native'`）は `thread/shellCommand` の結果が Codex の会話にすでに入っている。

2026-09-28 にユーザーが、行ごとに「渡さない」を選べるようにすることを依頼した。

この ADR は 0054 を置き換えない。0054 の「次の人の発言と一緒に渡す」に、行ごとの例外を足す。

## 決定

- **出す場所**: ホストで走らせる会話（`'host'`。Claude と fake）の、まだ渡していない `!` の行（走っている間も、終わった後も）。見出し「あなた · 次の発言で {agent} に渡す」の横に「渡さない」を置く。
- **押したとき**: その行は次の発言でエージェントに渡らない。見出しを「あなた · {agent} に渡さない」、操作を「渡す」に替え、「渡す」で元に戻る。渡す前なら何度でも切り替えられる。走っている間に押してもよく、結果が出た後も渡らない。
- **次の発言の後**: 渡さなかった行は、渡さないまま会話に残す。見出しは「あなた · {agent} に渡していない」で、操作（渡す・渡さない）は出さない。開き直しても同じ形で、走らせた時刻より後の最初の人の発言の前に出す。
- **残し方**: 渡った合図で、`shellPending` から sessions.json の `shellKept` へ移す。会話ごとに新しい 20 件まで、出力は stdout・stderr それぞれ先頭 32KB まで（越えたら省いた印）。エージェントを切り替えて未送の追記を捨てるときも、「渡さない」の行は `shellKept` に移す。
- **切り替えられない間**: ターンの始めに渡す行を決めてから、渡った合図までは切り替えを断る（決めた後に替えても、その発言には反映できないため）。渡らずに終わったターンの後は、また切り替えられる。
- **Codex（`'native'`）では出さない**。結果が Codex の会話にすでに入っていて外せないため。サーバーも断る。
- **ほかの端末**: 切り替えは全部の接続に `shell.skip` で流し、次の発言の後は `shell.handed` の `keptIds` で「渡していない」にする。
- 口は WebSocket のコマンド `skipShell { sessionId, runId, skip }`。

## 理由

- 走らせたことは取り消せず、出力は見るまで分からない。渡すかは、出力を見た後に決めるのが自然。走る前の選択（モックの別案）は、出力を見るのに 1 手増え、走らせたことが送るまで会話に残らない。
- 渡さなかった行を消すと、何を走らせたかの跡が会話から消える。0054 の「会話にすぐ残すほうが正直」をそのまま保つ。
- Codex で「渡さない」を出すと、実際には渡っているのに渡っていないように見える。出さないほうが正直。
- 渡さなかった行は transcript に入らないので、Pleiad が持つしかない。出力は最大 256KB × 2 あり、積み続けると sessions.json（全部の会話で 1 つのファイル）が膨らむので、数と長さに上限を掛ける。

## 影響

- WebSocket のコマンドに `skipShell`、出来事に `shell.skip` が加わる。`shell.handed` に `keptIds` が加わる。
- sessions.json の会話の欄に `shellKept` が加わる。`shellPending` の行に `skip` が加わる。
- `loadSession` の発言に、`skip: true`（渡さない、まだ送っていない）と `kept: true`（渡していない）の `!` の行が入る。
- 20 件より古い渡さなかった行と、32KB を越えた出力は、開き直すと見えなくなる。
- 形は `docs/design-system.md`「入力欄のシェルの形」、口と保存は `docs/multi-backend.md`「シェルの行」。
