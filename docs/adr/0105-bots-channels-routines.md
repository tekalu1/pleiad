# 0105 bot・Channels・ルーティンを入れる。「グループ機能をやらない」は「会話を手で入れる器をやらない」に改める

- 状態: 提案

## 状況

Pleiad の会話は、人が開いて話し、終われば止まる。人と複数の AI が同じ場で話し続ける・決まった時刻や出来事で AI に仕事をさせる・AI が覚えたことを次の仕事に持ち越す、はいまは作れない。先行事例（チャンネルに常駐する bot、定期実行のエージェント）はあるが、どれも「1 本の会話を永遠に伸ばす」か「記憶を勝手に抜く」ことで、キャッシュの切れ・文脈の濁り・誤学習と記憶の汚染を起こしている。

[design.md §2.1](../design.md) は、機能の採否を「見るために離れる・思い出すために離れる・続けるために離れる」を無くすことへの寄与で決める（[ADR 0007](0007-symmetric-ai-and-human.md)）。design.md の「やらない」には「グループ機能。R3 と R5 で代替する。両方持つと『グループに入れる手間』= P2 の元凶が残る」がある。

2026-10-03 に、ユーザーが次の形を承認した（提案の本文と画面の案を含む。個々の決定は 0106〜0113）。

## 決定

- **bot・Channels・ルーティンを入れる。** Chats は今の「作業の会話」のまま、Channels は人と bot が集まる場。bot は「1 本の無限の会話」ではなく、名前・アイコン・人格・記憶・権限を持つ定義で、仕事はスレッドごと・bot ごとの会話として走る。ルーティンは時刻・間隔・イベント・webhook で bot に仕事をさせる。
- **3 つへの寄与で採る。** 思い出すために離れる → bot の記憶とチャンネルの履歴。続けるために離れる → ルーティンと、bot が他の会話へ代わりに送ること。見るために離れる → 変えない（スレッドの可視化・ファイルは Chats と同じ右パネルで見る）。
- **design.md の「やらない: グループ機能」を改める。** 「会話を手で入れて整理する器（グループ機能）。R3 と R5 で代替する。Channels は仕事が**始まる**場で、会話を後から入れる・移す操作は持たない」。会話を入れる手間が P2 の元凶だったので、仕事の始まり方（@ の投稿・ルーティン）で会話ができる形にし、後から移す操作は作らない。
- **[ADR 0007](0007-symmetric-ai-and-human.md) の対称性は保つ。** bot は会話に束縛された agent として操作の一覧（[ADR 0081](0081-control-surface-registry.md)・[0082](0082-control-surface-principals-and-risk.md)）の同じ表に載る。承認モードと記憶の消去は人間だけ（0108・0109）。
- **ADR は 9 本に分ける。** 0106 脇の 2 タブ、0107 投稿の正本、0108 bot の実体と起こし方、0109 記憶、0110 スレッドの空間モデル、0111 ルーティン、0112 webhook の受け口、0113 代わりに送る。段階は P1（Channels と bot）→ P2（ルーティン）→ P3（夜の整理・代わりに送る・webhook）。版は P3 まで入れてから 1 回で出す。

## 理由

- 1 本の会話を伸ばすと、圧縮のたびにキャッシュが全部切れる。スレッドごとに区切れば各会話は短く、先頭（人格）は共通にできる。
- 仕事の始まる場所を増やすだけで、既存の会話・状態・分岐の仕組みをそのまま使える（Channels は会話の器ではない）。同じ道具（右パネル・承認カード・検索）を共有でき、認知負荷が増えない。
- ルーティンの実行履歴をチャンネルのスレッドにすると、「昨夜何が起きたか」を探しに離れずに済む。
- 採らなかった案: Chats の一覧に bot の節を足す（並べ方と操作が違うものが混ざる。0106）、bot ごとに 1 本の常駐会話（キャッシュと文脈が濁る）、会話を後からチャンネルへ移す操作（グループ機能の再来）。

## 影響

- `core/` に `channels/`・`bots/`・`memory/`・`routines/` と、つなぎ目の `core/bots-host.mjs` が増える。操作は `core/ops/` に足す（直のツールは足さない）。
- 古い版へ戻すと、bot の会話を知らないので Chats の一覧に並ぶ（壊れはしない。`docs/desktop-releases.md`）。
- 規約: サブスクの認証で無人のルーティンを動かすことは、有人の利用より一段踏み込む。画面には出さず、利用者の判断に残す（0111）。
- 今の動きは `docs/channels.md` に書く。
