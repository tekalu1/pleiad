# 0048 委譲の子の無音と長いコマンドを親に知らせる

- 状態: 承認（2026-09-28）

## 状況

委譲の子が終わらないコマンドを待っても、タスクは実行中のままで親に完了通知が届かない。出力が続く長いコマンドは無音だけでは検知できず、Claude の background 起動結果や Codex のターン終了もコマンドの完了とは限らない。

## 決定

- 子の無音が 5 分に達したら親へ知らせる。`AGENT_HOST_TASK_SILENCE_MINUTES` の既定は 5、0 は無効。承認待ちは除外し、再開から数え直す。Claude の `tool_progress` と Codex のコマンド出力差分も活動として扱う。
- 子ごとに複数の実行中コマンドを保持し、1 コマンドの経過が 5 分に達したら一度だけ知らせる。`AGENT_HOST_TASK_COMMAND_MINUTES` の既定は 5、0 は無効。出力や別の活動では期限を延ばさず、承認待ちは含めない。開始が分からなければ観測開始からの下限として伝える。
- 通知は既存の無音・完了通知と同じ配送条件を使う。親が受け取れない間は保留し、送信前に通知済みを保存する。未受領のみ再送し、受領が不明なら重ねて送らない。コマンドごとに独立した通知 ID を使う。
- **コマンドを自動で止めない。** 委譲の子でもユーザーの会話でも、時間だけで停止しない。旧来の子のバックグラウンド作業を 10 分で止める処理を廃止する。通知は親に `ply_task_status` と `ply_task_cancel` を案内する。
- 指示で予防する。子にだけ、コマンドの時間上限、常駐するサーバーやアプリのバックグラウンド起動と PID の記録・停止、`Start-Process -Wait` のような無期限待機の禁止を伝える。Claude / Codex は既定の子向け指示、Antigravity はカスタムエージェントの本文へ追加する。編集済みの指示は上書きしない。

## 理由

2026-09-28 の利用者の決定。意図して実行している長いコマンドを誤って止めないため、経過時間で知らせ、停止の判断は親または利用者に残す。Antigravity には Pleiad からコマンドを安全に個別停止する口がなく、文字列やプロセス木からの推測による停止は別の仕事を巻き込みうる。

無音とコマンドの時間を別々に持てば、出力のある長時間実行と、何も届かない待機の両方を捉えられる。バックグラウンド移行を終了と取り違えず、Codex のターン後にも残る端末を監視する必要がある。

## 影響

`ply_task_status` / `ply_task_list` に秘密値を伏せたコマンド本文・cwd・経過分数・開始の確かさを載せる。観測と開始の時刻を分け、実際の完了イベントで台帳から外す。Codex の子が完了しても残る端末は監視を続ける。再起動後の生存確認は行わず、保存済みコマンドは不明として再通知しない。親が忙しい場合は 5 分時点の即時配送を保証しない。画面の状態表示を増やさない。

子向け指示の追加は ADR 0023・0026 の注入経路を使い、追加依頼でも毎ターン適用する（ADR 0044）。既存の承認済み ADR の本文は変更しない。
