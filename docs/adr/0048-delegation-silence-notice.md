# 0048 委譲の子が無音になったら親に知らせる

- 状態: 提案

## 状況

委譲された子が終わらないコマンドを待ち続けても、状態は `running` のままで完了通知は届かない。Antigravity はターンの終了後に履歴を読むため、途中の活動を会話の保存記録だけからは判断できない。

## 決定

子ごとに最後のバックエンドイベントの時刻を持つ。Antigravity は履歴に残さない `step_update` も活動として数える。実行中の無音が既定 15 分に達したら、親へ専用の内部通知を 1 回届ける。閾値は `AGENT_HOST_TASK_SILENCE_MINUTES` で設定し、`0` で無効にする。人間の承認待ちは対象から外し、再開時から数え直す。新しい活動があれば次の無音期間として扱う。通知は子を停止しない。

## 理由

停止か長い処理かを自動で確定できないため、親に確認と停止の手段を示す。既存の完了通知と同じ配送条件を使えば、親のターンや人間の送信待ちを妨げずに知らせられる。

## 影響

タスクの記録に `lastActivityAt` と通知済みの時刻を追加する。`ply_task_status` / `ply_task_list` に無音分数を追加する。通知直前に通知済みの時刻を保存し、受領が不明な場合は重複して送らない。画面のバックグラウンド一覧には新しい印を設けず、従来の状態表示を保つ。
