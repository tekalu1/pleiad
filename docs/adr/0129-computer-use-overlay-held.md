# 0129 computer use の操作の合間も縁を残す

- 状態: 提案

## 状況

[ADR 0073](0073-computer-use-ui.md) では、オーバーレイ（縁・ピル）を最後の操作から 6 秒で消す。一方、ロック（[ADR 0072](0072-computer-use-lock-and-stop.md)）は最初の撮影か入力からターンの終わりまで持ち続ける。

委譲の子は、撮影と撮影の間に数分〜数十分、bash で待つ・別の MCP を呼ぶことが多い。2026-10-04 の実例（Studio Pro を操作する子）では、ロックを持った約 80 分のうち、枠が出ていたのは呼び出しの直後の数秒ずつだけだった。人には「サブエージェントの操作では枠が出ない」ように見え、触ってよいのかも分からなかった。調べると、親・ネイティブのサブエージェント・委譲の子のどれでも、呼び出しの直後には枠が出ていた。

## 決定

- 最後の操作から 6 秒たっても同じターンがロックの持ち主なら、消さずに「使用中」にする。消すのは、ターンの終わり・持ち主の変更・承認待ち（`hide`）・止めるとき（今までどおり）。時間では消さない。
- 「使用中」の縁: 呼吸を止め、にじみの深さを 10 DIP にし、縁の全体の不透明度を .6 にする（線の色と太さは操作中と同じ）。操作中から 600ms で移る（動きを減らす設定では 150ms）。霧のカーソルは引っ込める。
- 「使用中」のピル: 文言は「{エージェント名} が PC を使用中「{会話のタイトル}」」で、「Esc で止める」は出さない。ピルの不透明度は .8。
- 「使用中」の間は Esc を握らない。長く続くので、人がほかのアプリで押す Esc を奪わないため。止めるのは会話の「止める」。次の操作で操作中に戻ると、Esc も握り直す。
- 委譲の子のターンが終わってロックが親へ返ったら、親が最後に操作したディスプレイに「使用中」で出す。親は返った時点ではまだ操作していないが、ロックは持っているため。
- 持ち主が分からない（`computer-arm` がまだ届いていない）ときは、今までどおり 6 秒で消す。

## 理由

ロックを持っている間は、ほかの会話の操作も待たされ、人が触ると子の操作とぶつかる。画面の上の表示をロックと揃えると、「今 PC を AI が使っているか」が枠だけで分かる。操作中と同じ強さで出し続けると、作業の合間の長い時間ずっと邪魔になるので、薄くして区別する。

## 影響

- `desktop/computer-overlay.cjs` の phase に `held` を足す。描画への指示に `rest` を足す。
- 文言は `web/locales/*/desktop.json` の `computer.overlay.held`。
- ロックを持ったまま長く考えたり書いたりするターンでも、ターンが終わるまで薄い縁が残る。
