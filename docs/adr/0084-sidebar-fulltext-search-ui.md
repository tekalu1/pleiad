# 0084 脇の検索を本文まで: 平らな結果・抜粋から発言へ飛ぶ・検索欄への近道は Ctrl+Shift+F

- 状態: 承認（2026-10-03）

## 状況

脇の検索は題・状態・作業ディレクトリの絶対パスを、打った文字列全体の部分一致で探すだけだった。core には本文まで探す `sessions.search` がある（[ADR 0080](0080-session-fulltext-search.md)）。画面をそれに載せるにあたり、結果の見せ方・飛んだ先の扱い・絞り込み・キーを決める必要があった。形は AsIs / ToBe のモックでユーザーが承認した（2026-10-03）。

## 決定

形と大きさは [design-system.md](../design-system.md) §4.1「検索」。決めたことは次のとおり。

1. **結果は平らな一覧**（`role=listbox`）。状態ごとの木にしない。抜粋で 1 件が 3 行になり、木では見出しの分だけ結果が押し出される。状態は行の字で残す。関連度順と新しい順は 1 つのボタンで切り替え、端末に覚える。語を消すといつもの木に戻る。
2. **題・状態・場所は手元で即座に、本文は 120ms 後の `sessions.search` の結果で置き換える。** 照合の規則は core と同じ（AND・`"…"`・NFKC・場所はフォルダー名）で、同じ入力を両方に通して揃いをテストする。画面は新しい WS コマンドを足さず、汎用の `invoke('sessions.search', …)` で呼ぶ。
3. **抜粋を押すとその発言へ飛び、`note-flash` を 1 度付ける。** 会話の中の検索（[ADR 0063](0063-conversation-navigation.md) の D）は**開かず、語だけ引き継ぐ**。本文の一致に印が付き、Ctrl+F の 1 手で同じ語のまま残りの一致へ進める。会話の幅を削らず、狭い画面でシートが毎回上がるのを避ける。
4. **ツールの入力は既定で対象外**、**委譲の子は既定で含めない**。どちらも漏斗の「含める」で選ぶ（ツールの入力を含めると当たりが倍になる。委譲の子は実データで会話の半数近くあり、親と同じ話題が二重に出る）。委譲の子の行は場所の代わりに「委譲 · 親の題」。ツールの出力・thinking・圧縮の要約は対象にしない。
5. **絞り込み**: 期間（すべて / 今日 / 7 日 / 30 日。語が無くても木を絞る）を足す。語があるときだけ発言者（自分 / AI）と「含める」を出す。会話ごとの一致件数の札を題の右に出す。
6. **キー**: 検索欄へ移る近道は **Ctrl+Shift+F（macOS は ⌘⇧F）**。Ctrl+F は会話の中の検索のまま（Ctrl+K は採らない。ブラウザーのアドレスバーの検索と重なる）。語があるとき ↑↓ で結果を選び（`aria-activedescendant`）、Enter で抜粋へ飛び、Esc で語を消す。空の検索欄に入ると、結果を開いた語を 5 件まで（端末ごと）候補に出す。
7. **説明文は足さない**（[ADR 0018](0018-minimal-explanatory-text.md)）。文法の説明は画面に出さない。
8. **関連度の調整**: 新しさの減点に上限（3）を付け、全部の語が題に揃う会話も「揃う」の加点（+2）に数える。ADR 0080 の式では、1 年前の会話は題に当たっても本文だけの新しい当たりの下へ沈み続けた。

## 理由

- 探しているときは状態より「どれが当たりか」が先。見出しの分だけ行が押し出されず、一番の当たりが先頭に来る。
- 手元の即時の結果は、入力の待ち（120ms）の間も画面が空かないようにする。核心の照合を二重に持つので、揃いをテストで固定する。
- 近道に Ctrl+K を採らなかった理由: ブラウザーで開いたときアドレスバーの検索と重なる。Ctrl+Shift+F は、内蔵ブラウザーの Ctrl+Shift+B と同じ「Ctrl+Shift+文字」の並びで、Windows・Linux の主なブラウザーでは割り当てが無い。macOS の ⌘⇧F は、Chrome・Firefox のメニューに全画面の表示に関わる割り当てがありうるので、ページが止められない場合の確認が残る（Pleiad のデスクトップ版は Electron の既定のメニューで ⌘⇧F が空いている）。

## 影響

- `invoke` の `sessions.search` が画面の唯一の入口になる。サーバーが古いと本文は探せず、手元の結果のまま（失敗しても画面は動く）。
- 検索中の一覧は状態の木ではないので、並べ替えやドラッグでの状態の移動は、語を消してから行う。
- 会話の中の検索（`web/conversation-toc.mjs`）に、パネルを開かずに語と印だけを受け取る口（`carry`）が増える。
