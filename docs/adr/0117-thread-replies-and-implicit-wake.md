# 0117 bot のスレッドの返事は bot が人に向けて書いた文だけにし、作業ログは畳んで残す。`@` は発言者で数え方を分け、bot どうしの呼び合いは 6 回で止め、`@` の無い人の投稿は話している bot が受ける

- 状態: 提案
- 「bot どうしの呼び合いは 6 回で止めて『あなたが書けば続けます』と出す」（D6）は [ADR 0119](0119-channel-budget-and-resting.md) が置き換える（回数ではなくチャンネルの予算で止める）

## 状況

[ADR 0109](0109-bot-and-dispatch.md) では、bot のターンの投稿の本文は最終の返答（会話の最後の AI の発言）で、bot が同じターンに `channels.post` で同じスレッドへ書くとターンの投稿の本文を置き換える（進捗のチェックリスト）と決めた。`@` は人も bot も同じ規則で数え、bot 同士の呼び合いに上限を置かず、スレッドで `@` の無い人の投稿は、今作業中の bot が 1 体だけならその会話へ書き足し、それ以外は誰も起こさないと決めた。

2026-10-04 に、#test のスレッドで 2 体の bot（Claude と Antigravity）と話したところ、次のことが起きた。

- bot の人格の固定の文に「チャンネル・スレッドへの返事は `channels.post`」と書いてあったので、bot は `channels.post` で返事を書き、ターンの最後に「#test のスレッドに返事を投稿しました。『…』」と作業の報告を書いた。返事はターンの投稿に入ったが、終わりに最終の返答（報告）で上書きされ、送りたかった返事が消えた。同じターンの 2 回目の `channels.post` は 1 回目と同じ id を返して置き換えた。
- Antigravity は 1 ターンの文を 1 つの発言に続けて書くので、最終の返答に道具の前の独り言（「Server name is empty. Let me check the call_op schema.」）まで入った。
- 報告の文の中の全角の「＠マイケル」で、もう 1 体の bot が起きた。fake の 2 体では、全角の `＠` の起こし合いが 297 件まで止まらなかった。
- 人がスレッドで `@` を付けずに「どこで作業してるの？」と書くと、作業中の bot がいなかったので誰も返事をしなかった（「メンションしないと返信もらえない気がします。寂しいです」）。
- 同じ bot でもスレッドごとに別の会話なのに、bot が別のスレッドへ書いた「@自分」は、自分あてとして数えず何も起きなかった。

同じ日に、ユーザーが説明用のモックの選択肢から次を選んだ: 作業ログは返事の下に畳んで残す（D3）、人の全角の `＠` は有効（D4）、bot が他の bot を起こすのは行頭の半角 `@` だけ（D5）、呼び合いは連続 6 回で止めて「あなたが書けば続けます」と出す（D6）、メンション無しの人の投稿は最後に返事をした bot が答え、作業中の bot がいればそちらを優先する（D7。送る前に宛先を見せる UI は作らない）、別のスレッドの「@自分」はそのスレッドの自分を起こす（D14）。

## 決定

- **bot がスレッド（DM）で人に見せる投稿は、その bot が人に向けて書いた返事だけにする。** 返事はターンの最後の文章に書く（それがターンの投稿になる）。人格の固定の文を「今のスレッドへの返事は最後の文章にそのまま書く。作業の報告は書かない。`channels.post` は別のチャンネル・スレッドへ書くときに使う」に改める。
- **bot がターンの中で `channels.post` で自分のスレッドへ書いたら、それがそのターンの返事。** 最初の 1 件はターンの投稿に入れ（`new` の有無によらない）、2 件目からは新しい投稿にする（前の返事を同じ id で消さない）。そのターンは、終わりに最終の返答を投稿に書かない。ターンの投稿に入った返事の `@` も、新しい投稿と同じく書いたときに解く（強い bot への承認カードも同じ）。決めるのはその会話のターンを持つ dispatch で、`ChannelService.post` が書く前に聞く（ops が呼んだ会話の id を渡す）。
- **最終の返答は、最後の道具の呼び出しより後の文だけにする。** 会話の最後の AI の発言が、道具の後の文（無ければ道具の前で終わった最後の文）で終わるなら、その前を落とす。どのバックエンドでも、道具の前の独り言は返事の本文に出ない。
- **独り言・終わりの報告・道具の呼び出しは、返事の下の畳んだ「作業ログ」に残す**（D3）。最初は閉じていて、見出しに道具の数を出す。開くと、返事の本文以外の AI の文と道具の行（Chats と同じ折りたたみ）が発言の順に並ぶ。材料は bot の会話の履歴で、投稿には保存しない。
- **何を `@` と数えるかは発言者で分ける。** 人（と Chats の AI）は文中も数え、全角の `＠` も `@` と同じ（D4。日本語の入力で `＠` になるため）。**bot の投稿で bot を呼ぶのは、行頭の半角の `@名前` だけ**（D5。行頭に並べた `@A @B` は数える）。どちらも、コード・引用・同じ行で閉じる括弧と引用符の中は数えない。人格の固定の文にこの書き方を書く。
- **bot が bot を起こすのは、人が書かないまま 6 回まで**（D6。ADR 0109 の「上限なし」を改める）。数えるのは bot の投稿の `@` と、呼んだ bot へ返す返事。人が承認した `channels.wake` は数えない。7 回目は起こさず、スレッドに「あなたが書けば続けます」のシステムの投稿を 1 回残す。数は bot が起こして新しくできたスレッドの根（`origin` をたどった先）に持ち、人がそのスレッドか派生のスレッドに書くと 0 に戻る。
- **スレッドで `@` の無い人の投稿は、そのスレッドで話している bot 1 体が受ける**（D7）。今作業中（始めかけを含む）の bot が 1 体だけならそれ（途中送信。ADR 0109 の規則のまま）。そうでなければ、最後に話した bot = その投稿より前の、いちばん新しい bot の投稿の bot が、新しいターンで返事をする（作業中なら途中送信）。bot の投稿がまだ無ければ、スレッドの会話を持つ bot が 1 体だけならそれ。決まらなければ誰も起こさない。送る前に宛先を見せる UI は作らない（選び直すときは `@` で指定する）。
- **bot・Chats の AI の `@` の無い投稿は、誰も起こさない。** 暗黙の宛先は人の投稿だけ。
- **自分への `@` は、書いた会話のスレッドの中でだけ数えない**（D14）。bot が `channels.post` で別のスレッド・チャンネルの流れへ書いた自分への `@` は、そのスレッドの自分の会話を起こす。

## 理由

- 人がスレッドで読みたいのは bot の返事で、bot が自分の作業を報告する文ではない。最終の返答と `channels.post` のどちらも「返事」になりうる作りで、指示は `channels.post` を勧め、仕組みは最終の返答を勝たせていたので、従った bot ほど返事を失った。指示を最終の返答に寄せ、`channels.post` を使った bot にも返事が残るようにすれば、どちらの書き方でも返事が残る。報告と独り言は消さずに作業ログへ畳めば、何をしたかは開けば読める。
- 2 件目を新しい投稿にするのは、`channels.post` は「投稿する」操作で、2 回呼んだ bot は 2 件書いたつもりでいるため。書き換えたいときは `channels.edit` がある。
- 独り言を落とす規則を「最後の道具の後の文」にしたのは、バックエンドの記録の形（発言の分け方）によらずに同じ結果になるため。
- bot の `@` を行頭の半角に限ると、bot が文中で相手の名前に触れただけ（「＠マイケルに返事しました」）では起きず、呼ぶときの書き方は 1 つに決まる。人の書き方は変えない（日本語の入力の全角を含めて、今まで効いていたものを効かなくしない）。
- 上限が無いと、書き方の事故（全角の起こし合い）が人の［止める］まで続き、費用がかかり続ける。6 回は、呼んで答えて返す往復を 3 回できる数で、続けたければ人が 1 行書けばよい。
- `@` の無い投稿の宛先を「話している bot」にしたのは、人はスレッドで直前の返事に答えることが多く、宛先が 1 体に決まるため（複数の bot がいるスレッドで全員が起きない）。宛先を人の投稿に限るので、bot どうしの暗黙の起こし合いは生じない。
- 採らなかった案: スレッドの全ての bot を起こす、毎回宛先を選ばせる（D7 の B）、作業中の bot だけを起こす（今までの規則。会話が途切れる）、bot の `@` を本文から外して呼び出しの操作だけにする（D5 の B）、`channels.post` を自分のスレッドへは断る（従わない bot の返事が失われる）、作業ログを出さない（D3 の B）。

## 影響

- ADR 0109 の「スレッドで @ の無い人の投稿」「ターンの中の `channels.post` はターンの投稿の本文を置き換える（進捗）」「bot 同士の呼び出しに上限を置かない」「@ は人も bot も同じ規則」は、この ADR に置き換わる。進捗のチェックリストを書き換えたい bot は、自分の投稿を `channels.edit` で直す。
- 返事を書いたターンの作業の報告は、返事の本文には出ず、作業ログと bot の会話（投稿の ⋯ の「会話を開く」）に残る。
- `@` を付けない人の投稿でも bot が起きるので、メモのつもりの投稿にも、話している bot が返事をする。止めたいときは［止める］。止めた後に人が書くと、また話している bot が受ける。
- 人の `（@Owl に聞いた）` のような括弧の中の名前は、もう bot を起こさない。
- `ThreadState.chain`（任意の欄）を足した。保存の形（表・形式番号）は変えていない。古い版に戻すと、ターンの投稿は最終の返答で上書きされる動きと、上限の無い呼び合いに戻る（`chain` は読まれない）。
- `@here`・`@everyone`（D8・D9。人が書いたときだけ、起こす前に「◯体を起こします」の確認を出す）は、入力欄まわりの確認の札が要るので、入力欄の作り直しが入った後に別に足す。
