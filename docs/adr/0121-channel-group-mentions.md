# 0121 人の @here / @everyone は宛先を数えてから起こす

- 状態: 承認（2026-10-04）

## 状況

個別の `@名前` だけでは、スレッドで話した bot やチャンネル全員へ一度に声をかけられない。集団宛ては複数の bot を動かすため、投稿前に人数を見せる必要がある。

## 決定

- `@here` はそのスレッドで話したことがある、今もチャンネルのメンバーである bot 全員。チャンネルの流れでは 0 体。`@everyone` はチャンネルのメンバーの bot 全員。両方や個別の `@名前` を併記しても同じ bot は一度だけ起こす。
- 人の投稿だけで有効。bot の投稿にこの語があっても起こさず、起こされた bot の返事から連鎖させない。`here` と `everyone` は bot の予約名にする。
- 人が送る前に必ず入力欄で「N体を起こします」を出し、［起こす］を押すまで投稿も起動もしない。宛先チップは出さない。投稿時に宛先を数え直し、確認した id と違えば送らず再確認する。投稿には解いた bot の id を残し、後でメンバーや名前が変わっても起こした理由を追える。

## 理由

人数を投稿前に見せると、意図しない一斉起動を避けられる。投稿時の再確認は、確認後にメンバーやスレッドの発言者が変わった場合に別の bot を起こさないため。

## 影響

`channels.wakePreview` と `channels.post.confirmedWake` を追加する。入力欄は ADR 0116 の composer を使い、起動判定は既存の dispatch を通す。
