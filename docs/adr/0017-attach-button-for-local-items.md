# 0017 手元のものを渡す入口は添付のボタン

- 状態: 承認（2026-09-23）

## 状況

リモート（0013）で使うと、「この端末にあるファイル」と「ホストにあるファイル」の 2 つの出どころができる。最初は、手元のフォルダーを送る入口を作業ディレクトリの面（入力欄のチップ）の上のタブ「ホストのフォルダー / 手元から送る」に置いた。

## 決定

- 手元のファイル・フォルダーを渡すのは添付と同じ種類の操作なので、**入口は添付（クリップ）のボタン**にする。同日に作業ディレクトリの面のタブから移した。作業ディレクトリの面はホストのフォルダーだけを扱う。
- 出どころを選べる接続（リモートの窓・モバイル版の殻・ホストの画面ではないブラウザー）では、クリップで見出しを分けた面を開く: 「この端末から」（ファイル…、デスクトップ版のリモートの窓だけフォルダーを送る…）と「ホストから <ホスト名>」（ファイルを選ぶ…）。
- ホストの PC の窓・ホストで開いたブラウザーでは面を出さず、クリップはすぐファイルを選ぶ（ホスト = この端末なので）。
- ホストのファイルは送らずにパスのまま添付する。添付の札に出どころの印を付ける。

## 理由

- 利用者から見ると「会話に物を渡す」は 1 つの操作で、置き場が 2 つあると探す。
- 出どころを見出しで分けると、同じファイル名でもどちらのものか取り違えない。

## 影響

- 画面の規則は design-system.md「添付の出どころ」「手元のフォルダーを送る」、仕様は remote.md §8.1。
