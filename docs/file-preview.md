# ファイルを会話の横で読む

## 範囲（2026-09-15）

ファイルリンクは右パネルで開く。Markdown・HTML・画像/SVG・CSV/TSV・コード/テキスト・PDFに対応。原文切替、行指定、再読み込み、完全パスの確認、保存、幅変更、全面表示、会話への添付、狭い画面の全面プレビューを実装した。Office文書の変換表示は未対応で、保存を案内する。

取得は認証付き `/file-preview`、保存は既存 `/local-file` を使う。テキストはUTF-8で8 MiB、画像/PDFは32 MiBまで。原文は最大5000行（指定行の周辺を優先）、表は見出しと先頭500行・100列までを表示する。保存も32 MiBが上限。パネルは現在のファイルの取得時刻を表示し、自動では再取得しない。

HTMLは[可視化](visualize.md)と同じ隔離でスクリプトを実行する（2026-09-22、[ADR 0009](adr/0009-sandboxed-html-with-scripts.md)）。iframe は `sandbox="allow-scripts"` だけで `allow-same-origin` を付けず、`referrerpolicy="no-referrer"` と同じ `allow` 指定を持つ。CSP は可視化と同じもの（インラインのスクリプトと可視化の CDN 許可リストだけ、fetch/XHR/WebSocket・子フレーム・object・base・フォーム送信は禁止）を内容より前に置く。`<script>` とイベント属性は残す。ローカルの `<script src>` は認証経由で読み、スクリプト本文として埋め込む（各512 KiBまで。読めないものは省いて注記する）。外部の `src` はそのまま残し、CDN 許可リスト以外は CSP が止める。文書内のローカル画像・CSSは認証経由で解決して埋め込み、外部URL・追加のCSS import・フレーム・リンクによる遷移は無効にする。補助資源は24件・合計8 MiBまで、画像は各4 MiB、CSS・スクリプトは各512 KiBまで。省いた資源はパネルに表示する。Markdown内のファイルリンクはその文書のフォルダーを基準に開く。

ファイルの操作とパスの自動リンク（2026-09-23、承認済み）。ファイルが見える所（右パネルの頭の ⋯、ツリーの行の ⋯ と右クリック、ディレクトリのカード、会話のファイルリンク・画像）で同じメニューを開く: 右パネルで開く／ブラウザーで開く（HTML）／エクスプローラーで表示（フォルダーは「開く」）／パスをコピー／相対パスをコピー／保存／会話で使う。画像（本文の `![](…)`・Codex の生成画像・添付）はパスを持ち、下に所在の一行（ファイル名のリンク・フォルダー・⋯）を添える。押したときは今までどおり拡大表示で、下端にフルパスとコピー・右パネルで開く・エクスプローラーで表示・保存を並べる（パスの無い data URI の画像は保存だけ）。自動リンクは `web/file-reference.mjs` の厳しい判定（`looksLikePath`・`findWindowsPaths`）で、インラインコードの中身全体が 1 つのパス（ドライブ文字始まり、`./` `../` 始まり、区切りを含み最後が既知の拡張子）と、地の文の Windows の絶対パスだけ（日本語・空白・括弧で止め、末尾の句読点を外す）。コードブロックとリンクの中は対象外。読む・書く・編集の対象と添付の元パスもファイルリンクにする。存在は押したときに右パネルが確かめる。

作業ディレクトリのツリーは畳んだ状態で開き、頭の行のフォルダーのボタンで開く（2026-09-27）。開くと今のファイルまで祖先を開いて、その行を見える位置へ送る。開閉は同じパネルの中では保ち、閉じたら畳みに戻る（design-system.md「ファイルプレビュー」）。

OS の操作（エクスプローラー・既定のブラウザー）はサーバーのある PC で動くので、その PC の画面から見ているときだけ出す（[ADR 0010](adr/0010-os-actions-only-on-host-screen.md)）。サーバーは WebSocket の接続ごとに接続元がループバックで中継のヘッダーが無いかを記録し（`core/os-open.mjs` の `isLocalRequest`）、`hostCapabilities` で画面に伝え、`revealPath`／`openPath` は遠隔の接続から断る。パスは `/file-preview` と同じ許可範囲・同じ相対の解き方で、実体を解決した後の値を渡す。「開く」は `.html/.htm` のファイルだけ（既定のアプリで開くと `.bat` や `.lnk` が実行されるため）。Windows のブラウザー版は `%SystemRoot%\explorer.exe` に `/select,"…"` をシェルを通さずそのまま渡す（`cmd /c start` は使わない。終了コードでは失敗と判定しない）。デスクトップ版は本体が形を確かめ直して `shell.showItemInFolder`／`shell.openPath` で実行する。10 秒に 5 回までに制限し、失敗は画面下の短い知らせで示す。

PDFはPDF.jsを開いた時だけロードし、ページ移動・拡大縮小・ページ内テキスト表示を提供する。ブラウザー資源をローカル配信し、CDNに依存しない。Node 20系と互換のある5.5.207を固定（追加時のnpm auditでPDF.jsの既知の脆弱性なし）。開発環境の下限は依存の要件に合わせNode.js 20.19.0。APIの参考: [PDF.js examples](https://mozilla.github.io/pdf.js/examples/)。

同じパネルで[可視化](visualize.md)も開く（2026-09-16）。こちらは保存済みのスナップショットを `sandbox="allow-scripts"` で実行する。HTMLファイルも同じ隔離で動くが、こちらは現在のファイルを読む。読む対象が違うので、可視化では再読み込み・原文・会話で使うを出さず、「保存済みの可視化」と示す。保存はホストへ取りに行かず、会話に残っている内容を渡す。開いている間は会話の「サイドパネルに表示」に印を付け、閉じるとそこへフォーカスを戻す。

枠の操作（広げる／会話と並べて表示、閉じる／会話へ戻る）はアイコンにし、名前は title と aria-label に持たせる。パス欄にはコピーを置き、成功した場合だけボタンの上で知らせる。プレビュー／原文と下端の保存・会話で使うは文字のまま。

相対リンクは発言の時刻と作業場所の変更履歴から解決する。変更履歴があるのに時刻がない場合は場所を推測せず絶対パスを案内する。明示された別OSのパス・UNCパス・作業場所外・symlinkによる範囲外アクセスは拒否する。別会話や設定へ移動するとプレビューを閉じる。読み込みのキャンセルと世代番号で、遅い応答が次のファイルを上書きするのを防ぐ。

検証: パス・行指定・CSV・認証・作業場所の履歴・欠損・上限・symlink・保存・PDF資源配信を通常テストに追加。fakeサーバーを使い、実ファイルをクリックして表示、HTMLのCSS/画像と隔離、PDFの2ページ表示、保存、下書き保持、幅変更、360px表示、フォーカス復帰をplaywright-cliで確認する。

## 基本動作

- 普段は通常の会話。ファイルリンクには小さなファイル記号を添える。生のパスがリンクとして認識された場合も同じ入口とする。Web サイトへの通常リンクは従来の扱い。
- 押したファイルを右の一枚のパネルに表示する。次のファイルを押すと同じ場所で切り替わる。開いているリンクには「表示中」を添える。タブ列やファイル一覧は最初から増やさない。
- パネル幅は初期約48%。会話を最低360px確保し、境界のドラッグと左右キーで調整。「広げる」で読む面を広げ、同じボタンで会話との並列表示に戻す。
- 会話とプレビューは別々にスクロール。切り替えても会話の位置と下書きを保持。閉じる／Esc は元のリンクへフォーカスを戻す。入力欄の IME 変換中の Esc は奪わない。
- 見出しはファイル名、下に作業ディレクトリからのパス。長い名前は折り返す。完全パスは「パス」で確認・選択できる。コピーに成功した場合だけ成功を表示する。
- 「会話で使う」で入力欄へファイル参照を追加する。既存の下書きは保持し、自動送信しない。ファイル名だけから参照先を曖昧に推定せず、内部では完全パスを保持する。
- 760px 以下は画面内の全面プレビューに切り替え、ヘッダーの「会話へ」で戻す。背景にはフォーカスを移さない。会話で使う操作でも会話に戻る。

## ファイルと状態

| 種類・状態 | 最初の表示 | 次の操作 |
|---|---|---|
| Markdown | 見出し・表・リストとしてレンダリング | 原文と切り替え |
| HTML | 分離されたプレビューでレンダリング | 原文と切り替え |
| 画像 / SVG | 全体が収まるサイズ、寸法を表示 | 拡大・縮小 |
| CSV / TSV | 行・列を保持した表 | 原文と切り替え。大きな表は表示範囲を明示 |
| ソース / テキスト | 行番号つきの原文 | `:42` / `#L42` の指定行を強調しスクロール |
| PDF | ページとして表示 | ページ移動・拡大 |
| DOCX / XLSX / PPTX など | 未対応。ファイル名と理由 | 保存 |
| 読み込み中 | ファイル名は先に確定、「読み込み中…」 | 閉じる・別ファイルへ切り替え可 |
| 存在しない | 「ファイルが見つかりません」と探したパス | 再読み込み、パス確認 |
| 読み取り不可 | 「このファイルを読み取れません」と原因 | 接続先・アクセス権の確認へ |
| 大きすぎる / 未対応 | 制限・形式とファイル名 | 保存。本文としてバイナリを見せない |

## 読む対象の意味

リンクは**ホスト上に現在あるファイル**を読む。会話の過去時点の写しではない。取得時刻を表示し、再読み込みは明示操作にする。自動更新で読んでいる箇所を動かさない。Visualize の保存済みスナップショットとは区別する。

実装ではメッセージに対応する作業ディレクトリを使い、Windows ドライブ・POSIX 絶対パス・相対パス・空白・日本語・行番号を正規化する。ブラウザーの URL を基準に解決しない。別マシン上のパスをローカルと決めつけない。異なるディレクトリにある同名ファイルへ推測でフォールバックしない。

ファイル取得は既存の認証付きホスト経由。HTML/SVG は親画面から隔離し、外部通信・トップ画面への遷移・ホスト権限を渡さない。相対画像・CSS の扱いはホストで許可範囲を解決し、表示できない資源は明示する。HTML ファイルのスクリプトは既存 Visualize の分離方針（opaque sandbox・同じ CSP）で実行する。
