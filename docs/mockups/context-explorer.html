設定をメインパネルへ。コンテキストはエクスプローラーで見る

設定ダイアログをやめ、画面全体を設定に切り替える（左列が設定メニュー、右列がページ）。コンテキストの画面は「この会話の作業ディレクトリ」を自動で使い、開いた時点でスキャンし、見つかった指示・Skills・MCP をフォルダー階層で並べる。押すと右に中身が出る。

01

決めたこと

  • 設定はモーダルではなく画面全体。 開くと脇のセッション一覧は消え、その列に設定のメニュー（エージェント設定／使用量／外観／コンテキスト／アプリ情報・更新）が入る。右の列が選んだページ。今のダイアログの 2 列構成をそのまま画面に広げた形で、pill 列は置かない。戻るのは左列の上の「← 会話に戻る」か Esc
  • 場所の入力欄は無くす。 コンテキストの画面は今見ているセッションの作業ディレクトリを使う。セッションを選んでいなければ入力欄の値。見出しに「適用場所」として読み取り専用で出す
  • 開いたら自動でスキャン。「この場所の設定を開く」「保存済み設定でスキャン」の 2 ボタンをやめる。結果は場所ごとに覚えておき、次に開いたときは前回の結果を先に出してから裏で更新する
  • 結果はエクスプローラー風のツリー。 一覧の根は「ユーザー」（~）と「この場所」（Git ルート）の 2 つ。追加ルートがあれば 3 つ目以降に並ぶ。実際のフォルダー階層で並べ、見つかったファイルだけを出す（空のフォルダーは出ない）
  • 設定ファイルの中の登録も階層で出す。 .mcp.json や config.toml は展開でき、その中の MCP サーバーが子として並ぶ。ファイルを押せば全文、サーバーを押せばその 1 件
  • プレビューは右の列。 md はレンダリング（会話の返答と同じ描画 render.mjs を使う）。SKILL.md の frontmatter は表にして本文の上に置く。MCP は項目の表 + 元の記述。JSON / TOML はコードとして色付け
  • 探索の設定（探索元・対象・追加ルート・除外・読み込み担当）は同じ画面の中で切り替える。 見出し右の「探索の設定」を押すとプレビューの列がその画面に変わる。モーダルは重ねない
  • ツリーは部品として切り出す（web/tree.mjs）。 データ → DOM、開閉、選択、キーボード、絞り込みだけを持ち、中身の意味（コンテキスト）は知らない。後で「作業ディレクトリのファイルを見る」「添付を選ぶ」に使い回す
02

03

コンテキスト画面（操作できる）

ツリーの行を押す・矢印キーで動く・検索に打つ・種類の chip を切る・「探索の設定」を押す、が動く。データは agent-host の実際の配置を想定したダミー。

コンテキスト

（右の列だけ。左の設定メニューは §2）
適用場所D:\work\my-app 読み込み担当 ネイティブ 12 件 · 10:32 にスキャン

見出し行

  • 適用場所は読み取り専用。Git ルートと違うときは D:\work\my-app › temporary\worktrees\x のように根からの相対を添える（探索は根から作業場所まで）
  • 読み込み担当はスキャンの結果ではなく、この会話の方針。「共通読み込み」の会話では「Pleiad（指示・Skills）」のように種類を添え、固定された会話では「固定 · 9/14 10:02」と時刻を添える
  • 件数と時刻は等幅。スキャン中は件数の代わりに走る弧（§6 の印）
  • 「再スキャン」「探索の設定」は文字だけ。探索の設定を開いている間はその文字が青くなる

左の列（ツリー）

  • 面は --surface-1、角丸 20。選んだ行は白（--surface-paper）へ持ち上がる。脇のセッション一覧と同じ約束
  • 根の行は太字 + 等幅のパス。根は畳めない（畳むと何も残らない）
  • フォルダーは輪郭のフォルダー、指示は文書、Skill は星、MCP はプラグ。線幅 1.6 の弱い色。右端に「除外」「無効」「override を優先」の一語（候補のときは何も出ない）
  • 除外されたものは打ち消し線 + 弱い色で残す（消すと「除外したことを忘れる」）
  • 検索は一致した行を青くし、その祖先だけ残す。空になったら「一致なし」の一行
04

ツリー部品 web/tree.mjs

エクスプローラーの左側だけを部品にする。データ → DOM、開閉、選択、キーボード、絞り込み。行の中身（アイコン・右端の一語）は呼び出し側が関数で渡す。コンテキスト以外にも、作業ディレクトリのファイル閲覧・添付の選択・分岐の一覧に使える。

項目内容
データ{ id, name, children?, open?, data } の配列。children が無ければ葉。data は部品が触らない
生成createTree(root, { nodes, render(node, el), onSelect, onOpen })。render で行の中身を描く。無ければ名前だけ
DOM<div role=tree tabindex=0><ul><li role=treeitem aria-expanded aria-selected aria-level>。フォーカスは tree 1 つ（roving tabindex を持たない。行が多くても tab 1 回で抜けられる）
開閉chevron を押す、または行をダブルクリック。行の単押しは選択のみ。open の状態は呼び出し側が localStorage に持てるよう tree.state() で返す
キーボード↑↓ 移動、→ 開く／子へ、← 閉じる／親へ、Home / End、Enter = onSelect を再送（プレビューを更新）、文字 = その文字で始まる次の行へ
絞り込みtree.filter(pred)。一致した行と祖先だけ表示、一致行に .hit。祖先は自動で開く。解除で元の開閉に戻す
大きさ行の高さ 28、字下げ 16（脇のグループの行と同じ）。chevron 10px、アイコン 16px、隙間 5px
動きchevron の回転 120ms。開閉で高さはアニメーションしない（長い一覧で目が追えない）。prefers-reduced-motion で 0

行の状態

  • 枠線・片側の線は使わない。選択は白い面と 1px の影だけ
  • 今フォーカスしている行は 2px の青い輪（部品の外側と同じ規則）
  • 件数はフォルダーの右端に等幅で出せる（呼び出し側が render で決める）。コンテキストでは根だけに出す
05

プレビューの種類

押したもの上（見出し）本文操作
指示ファイル（CLAUDE.md AGENTS.md）名前 + 「指示」、パス、出典・適用範囲・状態・大きさmd をレンダリング。@path の参照先があれば末尾に一覧（押すとその行へ）除外する／除外を解除、パスをコピー
Skill（SKILL.md）名前は frontmatter の name。「Skill」frontmatter を表にして上に置き、本文を md でレンダリング。同じ名前が複数あれば「重複候補」の一行と相手へのリンク同上
MCP の登録（サーバー 1 件）サーバー名 + 「MCP」。親の設定ファイルのパス接続方式・コマンド・引数・env のキー（値は伏せる）・enabled を表に。下に元の記述（JSON / TOML）を「元の記述」の details に除外する、無効なら「元設定で無効」の説明
設定ファイル（.mcp.json config.toml .claude.json）ファイル名 + 「設定」ファイル全文をコードとして。MCP 以外の項目もそのまま見える（変えない）パスをコピー
フォルダー名前、パス直下の一覧（同じツリーの行と同じ見た目）。押すとそこを選ぶ—
スキャンの上限・読めなかったものツリーの最下部に「読めなかった 2 件」の行押すとパスと理由の一覧再スキャン
  • md の描画は会話の返答と同じ renderMarkdown。見出し・コード・表の見た目を二重に持たない
  • 本文の幅は返答と同じ最大 760px。長いファイルはプレビューの列だけがスクロールし、見出し行は残る
  • 「除外する」は探索の設定の除外パスに 1 行足すだけ。押すと行が打ち消しになり、見出し右の件数が減る。取り消しは同じ場所の「除外を解除」
06

会話からの入口

「この会話が何を読んだか」は会話側にも出す。タイトル行の右に小さく件数、押すと設定のコンテキスト画面（この会話の作業ディレクトリ）が開く。共通読み込みの会話では最初のターンの下に一行の記録が残る。

コンテキスト画面の設計
読み込んだコンテキスト → 指示 3 · Skills 7 · MCP 2（Pleiad が共通読み込み・9/14 10:02 に固定）中身を見る
  • 件数のボタンは弱い色。触れると本文色。既定から外れた読み込み（共通読み込み）のときだけ青
  • 会話の一行は「作業ディレクトリ → …」の既存の sys 行と同じ書式。ネイティブ読み込みの会話では出さない（Pleiad が把握していないものを断言しない）
  • 固定された会話でファイルが変わっていれば、件数の隣に「変更あり」の一語。押した先の見出し行に「9/14 に固定 · CLAUDE.md が変更されています」
07

確認したいこと

  • 設定の切替は上の pill 列でよいか → pill はやめ、設定中は脇のセッション一覧を出さず、その列を設定メニューにする（2026-09-15 決定）
  • ツリーの根は「ユーザー」「この場所」の 2 つでよいか。 別案は出典（Claude 形式／Codex 形式／共通）で分ける。フォルダーの実体と一致する前者が「エクスプローラー的」だと考えた。出典はプレビューの見出しで分かる
  • 設定ファイルの中の MCP 登録を「子」として展開する扱い。 ファイルとしての実体は無いが、探せる単位としては 1 件ずつなので子にした。違和感があればファイルを押したときの表の中だけにする
  • 「除外する」をプレビューから直接できてよいか。 探索の設定に行かずに 1 押しで除外できる。誤操作は同じ場所で戻せる
  • 他の設定ページも同じ画面に移す（エージェント設定・使用量・外観・更新）。中身は変えない。初回の「Pleiad へようこそ」だけは dialog のまま残す
