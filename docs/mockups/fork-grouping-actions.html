グループの操作 提案モック（つかんで状態を変える／入れる・外す・解除する）

検索▽

行やグループの見出しはつかんで別の状態へ落とせる。⋯（右クリックでも）で同じことがメニューからできる。

言葉

状態 = 見出し（`進行中` `レビュー待ち` … タグそのもの）。グループ = fork でつながった会話のまとまり。 「グループを作る／解除する」は会話のまとまりの話、「状態を変える」は見出しの話、と読み分けられる。

きまり

  1. グループに居る = 根と同じ状態。fork した子は親の状態を引き継いでグループに入る。
  2. 子の状態を変えると、その子はグループから出る。新しい状態の下に単独の行として並ぶ（会話の枝＝親子関係はそのまま）。
  3. 戻すときは状態を根に合わせる。「◯◯ のグループに入れる」は状態の変更も兼ねる。
  4. 根（グループの見出し）の状態を変えると、グループごと移る。中の会話も一緒に変わる。
  5. 作る: 行のメニューから「◯◯ のグループに入れる」。根の行からは「枝をまとめる」で散らばった枝を一度に。まとめる相手が無い行には、この項目を出さない。
  6. 解除: 見出しのメニューから。中の会話は独立した行になり、状態はそのまま。解除したことは覚える（自動で作り直さない）。
  7. どの操作も脇の下に一行出して 元に戻す。状態が黙って動く操作なので、取り消せることを見せる。

つかんで動かす

  • グループの中の行 → 別の状態へ落とす: 状態が変わり、グループから出る。
  • グループの中の行 → 今と同じ状態の空きへ落とす: 状態はそのまま、グループから出るだけ。
  • グループの見出し → 別の状態へ落とす: グループごと移る（中の会話も一緒）。
  • 単独の行 → グループの器へ落とす: そのグループに入り、状態が根に揃う。
  • 落とせる先は面が一段持ち上がって光る。線は引かない。キーボードからは ⋯ のメニューで同じことができる。

fork の印

fork で生まれた会話は、タイトルの前に枝の印を出す。グループから外しても、状態を変えても消えない （「この会話は誰かの続きだ」という事実は変わらないため）。印を押す必要はなく、見るだけのもの。
