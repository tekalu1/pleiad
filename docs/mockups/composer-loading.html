入力欄：待っている間の見せ方

場面
Pleiad
新しい会話
履歴を読み込み中…
Claude既定

方針

  • 新しい会話は、書ける状態を切らさない。空の会話なので、読み込むものが無い。今は開き直しと同じ処理（欄を無効にして下書きを読み直す）を通っているため、途中で書いた字が消える。欄はそのまま、書いた字は作成が終わったら本物の会話の下書きとして保存する。待つのは送信だけで、送信ボタンに走っている印（弧）を出し、押されたら「会話ができしだい送ります」と出して、できた時点で送る。
  • 書いても保てない場面（別の会話を開く・初回の接続）は、書けないことを見せる。欄の面は残し、中の字と案内を消して、弧・「履歴を読み込み中…」・流れる棒を出す。readonly と aria-busy を付け、ポインターは待ちの形にする。今は disabled だけで見た目が変わらないため、書けるように見えて打鍵が捨てられている。
  • 読み込みに失敗したら、欄を開放する。今は失敗すると欄が無効のまま戻らない。欄の上に理由と「もう一度読む」を出し、書くことはできるようにする（送信は読み込めてから）。
  • 150 ms より速く終わるときは何も出さない（ちらつかせない。design-system §4.6 と同じ）。新しい色は足さない。
