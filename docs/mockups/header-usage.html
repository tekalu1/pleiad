  1. 置き場所は会話のヘッダーの右。「コンテキスト」と「…」の間に置く。送る直前に目に入る位置で、脇を閉じていても、スマホでも見える。
  2. チップはこの会話のエージェントだけを出す。5 時間と週次のうち、使用率が高いほうを 1 つだけ（例「5時間 62%」）。スマホでは短い棒と数字だけ（上限に達したら「上限 14:30」）。
  3. 80% 以上で濃い色（太字にはしない）。差し色（赤紫）は「あなたを待っている」専用なので使わない。上限に達したら、率の代わりに回復する時刻を出す。
  4. 押すと全エージェントの一覧。この会話のエージェントを先頭に置く。トークン数・費用などの詳しい数字は、これまでどおり設定の「使用量」で見る。
  5. 更新の頻度: 5 分ごと、ターンが終わった直後、一覧を開いたとき。取得に失敗したら直前の値を薄く出し、時刻を添える。
