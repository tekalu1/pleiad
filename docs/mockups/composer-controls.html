ご指摘現状の原因提案
ボタンが多い作業ディレクトリ・エージェント・モデル・アカウント・エフォート・承認モードが並列（最大 7 個）「どこで」「誰が・どれだけ考えて」「どこまで任せるか」の 3 つのチップに。エージェント・アカウントはモデルのパネルの中へ
「既定」が何か分からない選択肢の値が空文字（""＝指定しない）で、実体を引いていないチップは常に実際に使う値を出す（例: Opus 5.5 · high）。一覧では「既定」は札として添えるだけ。Claude は SDK の supportedModels()（resolvedModel・対応エフォート）、Codex は config/read と model/list で解決できる
バージョン名が無いラベルが core/backends/claude.mjs の固定文字列（Opus / Sonnet…）SDK の displayName / resolvedModel から「Opus 5.5」と出す。取れないときだけ固定の名前に戻す
エフォートをスライダーにstrict な combo（文字の一覧）段階スライダー。段はモデルの supportedEffortLevels に合わせ、既定の位置に目印。非対応モデルでは無効化して理由を出す
青太字とグレーの差「既定から外れた設定は青く太く」という規則（design-system.md）。説明が無く、既定が見えないので意味が伝わらない全チップ同じ字にする。差を付けるのは意味がある 1 箇所だけ: 承認モードが YOLO のときに記号と強い字で警告
エクスプローラーで選びたい最近の履歴と手入力のみパネル下に「フォルダーを選ぶ…」。デスクトップ版は既にある plyDesktop.chooseFolder()（OS のダイアログ）を使う。ブラウザー版はサーバーが一覧を返す簡易ブラウザー
