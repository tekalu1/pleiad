# 自己署名評価版の検証（2026-09-18）

対象は Windows x64、Pleiad 0.1.0-beta.2。配布先は当時の非公開の旧リポジトリ（現在は public の `tekalu1/pleiad`）。

- 評価用のコード署名証明書を作成し、秘密鍵を CurrentUser/My に非エクスポート可能で保存した。
- 公開証明書のみを CurrentUser/Root に登録した。拇印不一致の信頼操作は拒否される。
- インストーラーとアプリの Authenticode 検証が Valid で、指定した証明書に一致した。
- 実際の electron-updater の検証器で、信頼した署名は受け入れ、異なる発行元と改変した実行ファイルを拒否した。
- 更新開始側には、現在のコードに旧バージョン番号を付けた自己署名済みの検証用 beta.1 を用いた。公開済みの未署名 beta.1 は変更していない。
- ループバックHTTPで実際の beta.2 インストーラーを取得し、ダウンロード進捗と署名検証、保存確認、更新ロック、Pleiad終了、NSISによるインストールを確認した。
- 専用データで再起動した beta.2 の更新完了通知を確認し、保存した会話を選ぶと下書きが入力欄に戻ることを確認した。
- `npm test` は 1,323 / 1,323 判定、62本が通過した。

インストールは実際のNSISをサイレント実行した。テスト用データを引き継ぐため、再起動は検証プログラムから別途行った。
通常のインストーラー画面からの自動再起動、GitHub Releasesからの実配信、Windows ARM64は未検証。
（2026-09-22 追記: 更新時の画面つき適用と自動再起動は、stub 版で手元確認した。手順は [desktop-releases.md](desktop-releases.md#インストーラー画面の手元確認windows)）
