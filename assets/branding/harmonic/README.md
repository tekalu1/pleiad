# Harmonic ロゴ

2026-09-12 採用の D1 アイコンと文字ロゴを SVG 化したマスター。

- `harmonic-icon.svg`: 正方形のアイコン。4 本の独立したカプセルを図形で再構成。ファビコン向け。
- `harmonic-wordmark.svg`: 文字単体。採用画像の輪郭をパス化したもので、フォント不要。
- `harmonic-lockup.svg`: 同じアイコンと文字を組み合わせた横組み。

背景は透明。色はプライマリー `#3A499E`。SVG のルートの `fill` で色を変更できる。
画像埋め込み、外部参照、スクリプト、フォント依存はない。
文字の輪郭は採用画像に基づくため、元の書体ファイルを必要としない。

SVG レンダラーで全ファイルの表示と、アイコンの 16 / 32 / 48px 表示を確認済み。
アプリへの組み込みとプロダクト名の変更は、この素材作成には含まない。
